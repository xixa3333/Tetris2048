# 版本資訊

## 2.4.0（本次測試版）

- 玩家可見名稱調整為 **BlockMerge 2048**，避免與既有品牌名稱混淆。
- 彩色拼片資產改成中性檔名與圓角寶石風格，移除舊的形狀字母命名。
- 修正滑動時前方拼片可移動、卻錯誤卡住後方拼片的問題；模式 1、模式 2 都套用依賴式同步滑動。
- 消除音效與 Game Over 音效共用同一個效果音量設定。
- 新增第七種 aqua 青色水平翻轉角形拼片。

## 2.3.9

- 加入模式 1 與模式 2。
- 模式 1 保留 v2.3.8 的同色連動玩法。
- 模式 2 改為同色相鄰也保持不同物件，玩法較輕鬆。
- 排行榜依模式分開記錄。
- 修正動畫外框、全球排行榜模式篩選與合法位置判定。

## 2.3.8

- 加入設定頁、背景音樂音量、效果音量與種子設定。
- 修正 Firestore 預設資料庫 URL。
- 改善暱稱 Unicode 驗證。
- 加入啟動時版本更新檢查。

## 2.3.7

- 修正合法位置判定，避免仍有空位卻提早 Game Over。
- 重新整理 README 與版本資訊。
- 加入主畫面版本號。
- 改善排行榜與登入相關流程。

## 2.3.6

- 保留 Firebase 內部登入相容性。

## 2.3.5

- 加入 APP 資訊頁與版本摘要。
