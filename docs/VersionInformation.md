# 版本資訊

## 2.5.0

- 遊戲回合與 APP 畫面流程改寫為階層式狀態機（`src/state_machine.lua`）；回合階段與畫面群組都成為明確狀態，輸入鎖由 busy 複合狀態統一持有。
- 回前景會回到原本的頁面；選模式途中離開則退回封面。
- 設定頁加入即時預覽：調整音量或背景音樂會立刻套用，按「儲存設定」才寫入，取消或離開會還原。
- 離線可用：連不上伺服器改為快捷登入，沿用上次登入的身分，不再因為一次離線啟動就被登出。
- 離線只開放讀取本機排行榜與寫入本機紀錄；全球排行榜、暱稱、密碼在離線時會擋下並提示。
- 登入頁新增「快捷登入」入口：列出這台裝置登入過的帳號（最多 5 個，新到舊），可直接選帳號登入，
  每列右邊可單獨移除該筆快捷登入；移除不會刪除帳號或排行榜紀錄。
- 登出只清除該帳號的雲端憑證，身分仍留在快捷登入清單，標示「本機」代表要重新輸入密碼才能用雲端功能。
- 修正快捷登入以本機身分進入時，因為沒有 idToken 而讓 APP 直接崩潰的問題。
- 帳號頁新增刪除帳號：需要網路、二次確認，並依序刪除全球紀錄、玩家資料、帳號本身，本機紀錄保留。
- 本機最高分自動同步：開啟遊戲有網路且已登入、登入完成、離線回前景換發成功、打開全球排行榜時都會補傳。
- 從未登入過的裝置以「訪客」保留本機紀錄，登入後不併入任何帳號；0 分不再產生任何雲端寫入。
- 修正 Firebase 設定載入：模擬器無法 require 含點檔名，改用 loadfile 補位並保留安全預設值。
- 全球排行榜寫入的版本欄位改讀 `app_info.currentVersion`，不再寫死 2.3.9。
- 清除舊版殘留：移除 `GameLogic.move`、未接上遊戲的同色相鄰放置規則、重複宣告的舊版設定畫面與 `Board.slide` / `Board.place` 薄包裝。
- 新增變異測試（遊戲內核心規則與遊戲外服務分開統計），強化測試品質。
