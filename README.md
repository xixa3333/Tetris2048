# BlockMerge 2048

BlockMerge 2048 是一款以「滑動拼片、整線消除、分數挑戰」為核心的原創益智遊戲。玩家不是控制掉落物，而是在每回合把場上的拼片往一個方向推動，完成消除後再放入下一個拼片。遊戲保留黑色背景與明亮色塊的簡潔風格，並在 v2.4.1 加入可擴展背景音樂選擇，讓玩家能依心情選擇輕鬆或恐怖風格音樂。

## 遊戲規則

- 棋盤大小為 10 × 10。
- 每回合選擇一個方向，場上所有拼片會同步往該方向滑動。
- 移動後會先檢查消除，再把 Next 區的拼片放到合法位置，放置後會再檢查一次消除。
- 如果目前方向與旋轉狀態找不到合法放置位置，才會 Game Over。
- Reserve 可以暫存或交換下一個拼片。

## 模式

- 模式 1：同色相鄰會視為同一物件一起移動，較需要規劃。
- 模式 2：同色相鄰仍保持不同物件，玩法較輕鬆。
- 本機排行榜與全球排行榜都會依模式分開記錄。

## 得分機制

- 每完成一條橫列或直行消除即可得分。
- 每條消除線得 10 分。
- 同一次可同時消除多條線。
- 移動後與放置後都會進行消除判定。
- 0 分不會計入排行榜。

## 遊玩方式

| 動作 | 鍵盤 / 手機 |
| --- | --- |
| 滑動拼片 | `W` / `A` / `S` / `D`，手機可用上下左右滑動 |
| 旋轉 Next 拼片 | `R` |
| 暫存 / 交換拼片 | `Space` |
| 回到主畫面 | 遊戲中可按主畫面按鈕 |

Game Over 後可以重新開始，也可以回到主畫面。

## 排行榜

- 排行榜需要登入帳號 ID。
- 本機排行榜會記錄本機不同帳號的遊玩分數。
- 全球排行榜每個帳號只顯示最高分。
- 每頁顯示 10 筆，支援模式 1 / 模式 2 分頁。
- 全球排行榜會顯示自己的名次，並用較亮背景標示自己的紀錄。

## 設定

- 背景音樂音量：只在遊戲進行中播放。
- 效果音量：同時控制消除音效與 Game Over 音效。
- 種子：輸入相同種子時，隨機序列會重現，適合想挑戰相同關卡流程的玩家。
